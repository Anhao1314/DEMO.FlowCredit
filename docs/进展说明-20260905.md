## 1. 项目概述

FlowCredit 是一个面向 AI 原生企业（GPU 算力 / API / 链上地址）的「链上可验证 AI 财务审计 + 动态授信风控」概念项目，当前主体是一个零构建纯静态演示站（原生 HTML/CSS/JS，file:// 即可运行），演示 P1 数据锚定 → P2 AI 风险评估 → P3 监控与压力响应的完整动线。

项目的演进方向已明确为：**基于 DeepSeek Harness（dsh）的 Web3 与数字金融 AI 风控审计平台**。计划采用六层架构（接入层 / 业务层 / Agent 层 / 可验证计算层 / 数据层 / 存证层），保留现有规则引擎作为确定性兜底，dsh 作为可替换的 AI 推理轨，所有评分结论附带证据引用与可重放的推理轨迹。

## 5. 风险与约束（持续关注）

- DeepSeek Harness（dsh）为开发者预览版，官方声明存在破坏性变更：必须保持适配层隔离，版本锁定，使其成为可替换推理轨。
- AI 评分结论强制证据引用、确定性规则兜底、抽样重跑与人审升级，压控幻觉与偏差风险。
- 对外表述使用「算法化评估」等措施语言，区分法定审计；数字金融相关主体资质要求前置确认。
- 原始业务数据永不上链，公网不泄露 API key：密钥只存在于服务端环境变量。
